## 0. 条件整理と全体モード構成

本作は以下の**2つの独立したゲームモード**を備え、タイトル画面から選択して開始できる。
1. **キャンペーンモード（CAMPAIGN MODE：全10ラウンド・完全1発勝負）**:
   - 各ラウンドで発射できる徹甲弾は**1発のみ**。ソナー反応から軌道を読み、命中すれば撃破（`RESULT_CLEAR` ➔ 次ラウンド、Round 10クリアで `ALL_CLEAR`）、外すか自機コアに被弾すれば即敗北（`RESULT_FAIL` ➔ 答え合わせアンベール表示＆0.5秒即時リトライ）。
   - 敵を遠距離（外周付近）で早く射抜くほど高得点となり、引き付けるほど減点される**距離比例スコアシステム**を採用。
2. **無限Wave防衛モード（ENDLESS WAVE MODE：複数敵防衛・自動装填・3段階フェーズ）**:
   - 有限予定時刻テーブル（Wave 1の3体〜Wave 11以降の最大8体）に従って出現する複数敵（独自ベクター進化2系統5形態：ランスI/II、ウイングI/II/III）を、**発射後2.0秒の自動装填**と**各Wave 1回の戦術パルス**で迎え撃つ防衛モード。
   - 各Waveは `ASSAULT（増援中） ➔ CLEANUP（増援終了・残敵掃討） ➔ REST（残敵0後の3.0秒安全休息）` の3段階で進行し、自機コア耐久（初期 `5`）が `0` になるまで続く。

## 1. レーダー座標系・空間パラメータ・表示領域仕様

### 1.1 固定キャンバスと最低ビューポート仕様
- **論理・表示キャンバス解像度**: **`960 × 720 px` 固定**（アスペクト比 4:3、CSSによる縮小は行わない）。
- **最低対応ビューポート**: **`1504 × 784 px`**（左右HUD・ヘッダー・余白を含む）。これ未満のウィンドウサイズでは全画面サイズ案内オーバーレイを表示し、マウスおよびキーボードのゲーム入力を無効化する。
- **レーダー原点 `(0, 0)`**: キャンバス中央 `(480, 360)` を論理座標 `(x: 0, y: 0)` とする。
  $$x = sx - 480, \quad y = sy - 360, \quad r = \sqrt{x^2 + y^2}, \quad \theta = \operatorname{atan2}(y, x) \pmod{2\pi}$$

### 1.2 主要リング半径と当たり判定定義（`CONSTANTS` 最新実装値）
| 名称 | パラメータ名 | 数値 (px) | 役割・仕様 |
| :--- | :--- | :--- | :--- |
| **レーダー外周半径** | `RADAR_RADIUS` | `360 px` | ソナー探知圏の外縁。自機弾はこの外周を超えた瞬間に飛翔完了（キャンペーンでは外れ確定）。 |
| **距離目盛りリング** | `RANGE_RINGS` | `90, 180, 270, 360 px` | `90 px` 刻みの4本の同心円。 |
| **危険領域リング** | `DANGER_RADIUS` | `120 px` | 敵の中心座標が $r \le 120\text{ px}$ に入ると接近警報（危険赤色表示＋高ピッチPing音＋キャンペーンでの `DANGER CLOSE PENALTY`）が発動。 |
| **自機コア半径** | `CORE_RADIUS` | `18 px` | 原点 `(0, 0)` に位置する自機タレットの半径。 |

## 2. ソナー・スイープ、ブリップ残像、戦術パルス、動的予測仕様

### 2.1 スイープ回転と角度跨ぎ検知
- **角速度**: $\omega_{\text{sweep}} = 1.25\pi\text{ rad/s}$（$225^\circ\text{/s}$、**1周 1.60秒** ※初版 `2.0s` から情報更新周期を改善）。
- **角度跨ぎ対応**: 前フレーム角度 $\theta_{\text{prev}}$ から現フレーム角度 $\theta_{\text{curr}}$ の扇形区間に敵角度 $\theta_{\text{enemy}}$ が含まれるかを厳密に判定し、$2\pi \to 0$ 境界でも検知漏れを起こさない（同一ターゲットへのスイープ再検知クールダウン `0.40秒`）。

### 2.2 ブリップ残像履歴（`blipHistory`）と進行方向・機動メタデータ
- スイープまたは戦術パルスがターゲットを通過した瞬間、その時点のスナップショット（`id, targetId, x, y, r, theta, heading, detectedAt, source, isDecoyEcho, round, turnSign, isBoosted, zigzagDir, formKey, formLabel` 等）を保存する。
- 各ターゲットにつき最新 **4件**（$B_0, B_{-1}, B_{-2}, B_{-3}$）、寿命 **`BLIP_LIFETIME = 6.0 秒`** で時間減衰表示する。
- **重要原則（カンニング・ネタバレ防止）**: 画面上のブリップ・ラベル・予測マーカーはすべて**検知されたスナップショット履歴のみ**から描画・計算し、未検知の実敵の現在座標や未来の変針・未観測の進化種は一切表示しない。

### 2.3 リアルタイム・リード予測マーカー（`computeDynamicLeadPrediction` / 「予測」表示）
- 対象ターゲットのブリップが2点以上観測されている場合、直近2点の速度・角速度と、最新検知からの経過時間 $\Delta t_{\text{blind}}$ ＋ 弾の飛翔時間 $t_{\text{ETA}}$ を反復収束させ、現在推定位置から弾着予測位置までのガイド線と黄色い予測マーカー（ラベル：`予測`）をリアルタイム表示する。
- 無限Waveモードでは、照準角度に最も近い観測済み個体を自動選択してその個体の予測マーカーのみを表示する。

### 2.4 戦術パルス（Tactical Ping）
- **発動入力**: 右クリック、`Shift` キー、または `E` キー（1ラウンド／1 Waveにつき **1回限定**）。
- **効果**: 原点から外周まで `PULSE_SPEED = 1440 px/s` で拡散する全方位リングパルスを放ち、通過した全ターゲットの位置を即座にブリップ記録する。
- **デコイ一斉看破（R5, R9, R10）**: 戦術パルスがデコイ（`isDecoyTarget(id)`）を通過すると、そのブリップに `isDecoyEcho = true` が記録され、グリッチ波形と `FAKE / DECOY`（R10では `FAKE #1`〜`#3`）ラベルで偽物であることが確定的に暴かれる。

### 3.2 距離比例スコア計算式（最大 `10,000 pts` / ラウンド）
命中確定時の本物ターゲット中心距離 $r_{\text{impact}}$ に基づき、遠くで仕留めるほど高得点、引き付けるほど減点とする。
1. **距離迎撃スコア（`distanceScore` / `baseScore`：最大 `6,000 pts`、最小 `300 pts`）**:
   - **通常・遠距離域（$r_{\text{impact}} \ge 120\text{ px}$）**:
     $$u = \operatorname{clamp}\left(\frac{r_{\text{impact}} - 120}{340 - 120}, \; 0, \; 1\right), \quad \text{distanceScore} = \operatorname{round}(2000 + 4000 \cdot u) \quad (2,000\text{〜}6,000\text{ pts})$$
   - **危険接近域（$r_{\text{impact}} < 120\text{ px}$：`DANGER CLOSE PENALTY`）**:
     $$u_{\text{danger}} = \operatorname{clamp}\left(\frac{r_{\text{impact}} - 34}{120 - 34}, \; 0, \; 1\right), \quad \text{distanceScore} = \operatorname{round}(300 + 900 \cdot u_{\text{danger}}^2) \quad (300\text{〜}1,200\text{ pts})$$
2. **精密射撃ボーナス（`precisionBonus`：最大 `1,500 pts`）**: $\operatorname{round}\big((1 - \operatorname{clamp}(\text{hitOffsetPx}, 0, 22) / 22.0) \times 1500\big)$
3. **暗闇予測ボーナス（`blindBonus`：最大 `1,500 pts`）**: $\operatorname{clamp}\big(\operatorname{round}((\Delta t_{\text{blind}} / 1.20) \times 1500), 0, 1500\big)$
4. **戦術パルス温存ボーナス（`noPingBonus`：`1,000 pts`）**: パルス未使用時 `+1,000 pts`、使用時 `0 pts`。
5. **称号フラグとランク閾値**:
   - `isLongRangeSnipe`: $r_{\text{impact}} \ge 240\text{ px}$ / `isDangerClose`: $r_{\text{impact}} < 120\text{ px}$ / `isBullseye`: $\text{offset} \le 6\text{ px}$ / `isBlindSnipe`: $\Delta t_{\text{blind}} \ge 0.80\text{ s}$。
   - **ラウンド単体ランク**: `S` ($\ge 7,500$), `A` ($5,500\text{〜}7,499$), `B` ($\le 5,499$)。
   - **全10ラウンド総合ランク**: `S` ($\ge 70,000$), `A` ($50,000\text{〜}69,999$), `B` ($\le 49,999$)。

## 4. 無限Wave防衛モード（ENDLESS WAVE MODE）詳細仕様

### 4.1 状態遷移とWave進行の3段階フェーズ
- **モード識別**: `game.mode = 'ENDLESS'`（キャンペーンは `'CAMPAIGN'`）。
- **主要状態**: `PLAYING`（Wave内部フェーズ `ASSAULT` ➔ `CLEANUP`） ➔ `WAVE_REST`（3.0秒の安全休息） ➔ 次Waveの `PLAYING`。コアHPが `0` に達した瞬間に `ENDLESS_RESULT` へ遷移し、戦績スナップショットを固定する。
- **有限予定攻勢（`buildEndlessWavePlan`）**:
  - 撃破数や生存数に関わらず、各Waveで定義されたイベント時刻（Wave 1〜2: 3体 `0/3.2/6.4s`、Wave 3〜4: 4体 `0/3.2×2/7.6s`、Wave 5〜6: 5体、Wave 7〜8: 6体、Wave 9〜10: 7体、Wave 11以降: 最大8体 `0/3.2×2/6.4/8.8×2/11.2×2s`）に確定出現する。処理待ちcapやバックログ補充は行わない。
  - 最終出現時刻から `1.6秒` 経過（Waveにより `8.0〜12.8秒`）で増援終了となり、`CLEANUP`（増援なし・残存敵は引き続き危険）へ移行する。
  - 予定された全敵が出現済みで、生存敵が `0` になり、かつ飛翔中の弾および戦術パルスの判定がすべて完了した時点で `WAVE_REST`（3.0秒の安全休息）へ突入する。

### 4.2 兵装・自動装填・コア耐久・統計ルール
- **コア耐久（Core HP）**: 初期値 `5`。実敵が $r \le 34\text{ px}$ に到達するごとに `-1` ダメージを受けてその敵は退場する（重複減算なし、回復なし）。`0` 到達で即座に `ENDLESS_RESULT`。
- **自動装填（Auto-Reload）**: 装弾数 `1`。発射時点から **`2.0秒`** で自動再装填される。弾が外れても即敗北にはならない。装填中や休止中の不成立入力では発射数や装填期限を更新しない。
- **戦術パルス**: 各Waveにつき `1回` 使用可能。次Wave開始時に `1` へ復元される。`WAVE_REST` 休止中は射撃・戦術パルスともに発動不可（ただし装填タイマーは進行する）。
- **統計計算（発射単位管理）**:
  - 各発射に固有の発射IDと `hitCounted` フラグを持たせ、1発の直撃＋プラズマ爆風で複数体を同時撃破した場合でも「命中した発射数（分子）」は `+1` として計上する（命中率が100%を超えない）。0発終了時の命中率表示は `"—"`。
  - 到達Waveは「開始した最大Wave番号」を記録する。

### 4.3 旧版の独自ベクター2系統5形態（改訂前の記録）
デコイは無限Waveモードには出現せず、すべての敵が実敵（`isDecoy: false`）として以下の2系統5形態で段階導入される（HP水増しなし、すべて直撃 `28px` または爆風 `44px` の1撃で撃破可能）：
1. **ランス系統（直線・加速系）**:
   - **ランスI（Wave 1〜）**: 三角輪郭、一定動径速度 `22 px/s` で直進接近。
   - **ランスII（Wave 6〜）**: 三角輪郭＋双発推進器装備、個体齢 `3.2〜4.4秒` にかけて動径速度 `18 → 24 px/s` へ滑らかに加速。
2. **ウイング系統（旋回・変針系）**:
   - **ウイングI（Wave 2〜）**: 三日月輪郭、動径 `22 px/s` ＋ 一定旋回角速度 `±0.06 rad/s`。
   - **ウイングII（Wave 4〜）**: 三日月輪郭＋可動翼装備、個体齢 `3.2〜4.4秒` で旋回方向を一段変針（smoothstep補間）。
   - **ウイングIII（Wave 8〜）**: 三日月輪郭＋二重可動翼装備、動径速度を **`20 px/s`** に抑え、個体齢 `3.2〜4.4秒`（一段目）と `6.4〜7.6秒`（二段目）で二段変針を行う。

- **敵の役割の見せ方**: 新しい敵種や攻撃ルールは追加せず、ランスI/II、ウイングI/II/IIIの既存5形態を、同時出現・近接ペア・後発敵との優先判断を生む順序で編成する。ランスIIの加速は「初速だけで脅威を判断せず、加速後に優先度を上げる」役割として扱う。ランスIIIは今回の必須追加としない。
- **Wave案**: Wave 1〜12の形態順、学習課題、初心者の想定失敗要因、予兆・復帰猶予は [level-design.md §6.4](./level-design.md) を参照。Wave 13以降は既知編成の循環とし、体数・速度・攻勢長を累積させない案。
- **初心者の難易度目標（仮説・未計測）**: 初回被弾の中心はWave 3〜4、Wave 6〜7は第2の被弾増加候補、初敗北の集中帯はWave 9〜12とする。これは強制敗北Waveではなく、初回プレイ群の到達分布として検証する目標。暫定指標は Wave 1〜2無被弾率 `80%以上`、初回被弾Wave中央値 `3〜5`、Wave 4終了までのゲームオーバー率 `10%以下`、Wave 12クリア率 `20〜40%`。
- **検証条件**: Wave別初回被弾・敗北率、Wave進入HP、敵別突破率、外れ後の再射撃成功、観測更新後の射撃、初心者の失敗理由理解を人間プレイで測る。各候補Waveへの到達例が不足する場合は目標を未確定とし、自動テストや最適AIの成功を体感の合格根拠にしない。
- **除外・要再承認**: デコイ／偽反応、新しい動径挙動・敵種、HP・装填・パルス・最大数・攻勢方式の変更、敵弾など新たな被弾経路は本提案に含めない。後から追加する場合は、既存要件との変更点を示して別途確認する。
