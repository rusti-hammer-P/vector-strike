# 要件定義・受け入れ基準（VECTOR STRIKE）

- **作品名**: VECTOR STRIKE（旧名: BLIND RADAR SHOT）
- **制作種別**: 新規プロトタイプ制作およびモード・UX拡張（最終体験確認はユーザー確認待ち）

## 1. ユーザー指定条件（確定）
- **ジャンル・コア体験**: 全方位2Dシューティング（2DSTG）のプロトタイプ。通常時は敵の姿が見えず、レーダー（ソナー／スイープ）でしか敵の位置がわからない状態で、敵の動きを読んで狙いを澄まし、**たった1発の一撃**を叩き込む緊張感と快感を楽しむ。
- **保存先**: `projects/blind-radar-shot/`（制作資料は `projects/blind-radar-shot/production/`）
- **対象環境**: PCブラウザ（HTML / CSS / JavaScript、外部ビルド不要でそのまま起動可能）
- **レーダー表現**: **ソナー／スイープ方式**（回転スイープバーやパルス波が通過した瞬間だけ敵の反応点・残像が光り、そこから移動先を予測して狙撃する）
- **一撃のルールと勝敗条件**: **完全1発勝負**（ターゲットに対し弾は1発のみ。命中すれば撃破・勝利、外すか敵の攻撃／接触で被弾すると敗北。リトライやステージ進行で繰り返し遊べる構成）

## 2. 明示的に委任された項目（「おまかせ」指定）
- **操作方法・自機の動き**: プロトタイプとして「ソナーで敵の軌道を読み、狙いを澄まして一撃を撃ち込む」面白さと緊張感が最も際立つ操作系（WASD/矢印移動＋マウス360度照準＆クリック発射、またはキーボード併用など）を専門役（Director / Planner / Designer）が設計・提案する。
- **ステージ・敵の挙動バリエーション**: 全10ラウンド構成（Round 1〜5の基本5タイプに加え、Round 6〜10として過去5タイプのパワーアップ上位変異版が登場する2部構成）。タイトル画面からR1〜R10を直接選択可能。
- **スコア評価ルール（ユーザー追加指定）**: **「敵を近づかせれば近づかせるほど点数が下がる（遠距離・早期のうちに少ないソナー反応から未来位置を読んで射抜くほど高得点）」** という距離比例スコア／接近減衰システムを採用する。
- **視覚・音響演出**: 添付参照された Web Audio API によるプロシージャル効果音（ソナーピング音、接近警報、照準ロック／発射音、撃破音など）や、暗闇に浮かぶレーダーUIの演出を専門役が設計する。

## 3. 受け入れ基準（Acceptance Criteria）
1. **通常時の不可視とソナー検知**:
   - 敵本体は通常時画面上に直接描画されない（暗闇／ステルス状態）。
   - ソナー（回転スイープまたはパルス）が敵の位置を通過した際のみ、反応点（ブリップ）と減衰する残像が表示され、複数回の反応から敵の移動方向・速度を読み取れること。
2. **一撃必殺（One-Shot）ルールと勝敗判定**:
   - 各ターゲット（ラウンド／フェーズ）に対して発射できる弾は **1発のみ**。
   - その1発が敵に命中すれば即座に撃破（CLEAR / 次ラウンドへ進行）となること。
   - 弾が外れて画面外へ消える（または不発確定）、あるいは自機が敵／敵攻撃に被弾した場合は即座に敗北（FAILED / GAME OVER）となり、素早くリトライできること。
3. **全方位（360度）の索敵・照準・射撃**:
   - 360度あらゆる方向から接近・移動する敵に対し、全方位へ照準を向けて射撃できること。
4. **プロトタイプとしてのゲームループ完結**:
   - タイトル／開始画面 → 戦闘（複数パターンのターゲットまたはラウンド） → 勝敗結果（命中精度やクリアタイム等のフィードバック） → 即時リトライ／最初から遊ぶ、の一連の遷移がエラーなく動作すること。
5. **検証可能性**:
   - PCブラウザで `index.html` を開く（またはローカルHTTPサーバー経由）だけで動作し、自動受け入れテストによって主要状態遷移・ソナー検知・1発勝敗判定が検証できること。
   - 中央プレイ領域は `960×720 px` で固定し、最低ビューポート `1504×784 px` 未満ではサイズ案内を表示してゲーム入力を無効にすること。
6. **無限Wave防衛モード（ENDLESS MODE：2026-11-05 承認追加）**:
   - 既存の全10ラウンド1発キャンペーンを完全に保持したまま、タイトル画面から別モードとして「無限Wave 防衛モード」を開始できること。
   - **有限の予定攻勢と3段階フェーズ**: 各Waveは撃破数や生存数によらず予定時刻に出現（偽像含む最大8枠、W1〜12の承認表、W13以降はW10/11/12の7/8/8枠循環、処理待ちcapなし）。最終出現から1.6秒で増援終了（`ASSAULT` ➔ `CLEANUP`：増援なし・残敵は危険 ➔ 残敵0かつ飛翔弾/パルス終了後に3.0秒の安全休息 `REST` ➔ 次Wave）。新Wave表の最終出現は最大20.0秒、攻勢終了は最大21.6秒。
   - **自動リロード・コア耐久・戦術パルス**: 装弾1発、発射から `2.0秒` で自動装填（外れても即敗北しない）。自機コア耐久 `5`（実敵突破ごとに `-1`、回復なし、`0` 到達で `ENDLESS_RESULT` 確定）。各Waveにつき戦術パルス1回使用可能。
   - **共通ロスター・ランスIIIと単色レーダー原則**:
     - キャンペーン由来の直線／折線ランス、旋回、急加速／横変位ブースター、周期／短周期スラローム、ミラージュ本体と偽像を、輪郭・基本挙動・対処で再認できること。モード別の速度・配置は [plan.md §4.6](./plan.md) に従う。
     - ランスIIIは無変針の超急接近直線型。W6の60px/sからW8以降72px/sへ進み、同時生存1体以内。全敵32px/s以下という旧上限は適用しない。初観測前突破を起こさず優先処理できる一方、全位相で外れ後再射撃を保証しない。
     - 偽像は予定枠に含み、コア損傷なし、親の撃破／突破で消滅。パルスで看破でき、偽像のみの撃破は実敵撃破数・命中発射数に加算しない。通常輪郭の手掛かりを残し、パルスなしでも識別を試せる。
     - 通常レーダー表示は単色（通常観測色）を優先し、系統・段階は輪郭・装備・観測名で伝えること（危険域の赤色を最優先し、進化段階ごとの多色化は行わない）。
     - 最新観測点の名称・ID・距離/観測年齢を3行ラベルとしてレーダー内側へまとめ、Canvas境界からはみ出さないよう位置補正すること。未観測の実敵情報や次Waveの具体種は開示しない。
