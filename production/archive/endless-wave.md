- 最新観測点の名称・ID・距離/観測年齢をまとまりとしてレーダー内側へ配置し、履歴点の減衰後も最新観測を読み分けやすくした。Canvas境界へ文字列がはみ出さない位置補正を追加。
- 有限予定攻勢、Wave配列/速度、10Rキャンペーン、入力、情報制約は変更なし。詳細な実装・試験・目視結果は `endless-implementation-report.md` / `endless-realtime-report.md` を参照。

### 委任された初期決定
- コア5、実敵突破1ダメージ・退場、回復なし。
- 装弾1、発射時から2.0秒自動装填。外れは即敗北しない。不成立入力で発射・期限更新なし。
- 全予定敵処理かつ飛翔弾等の判定完了後、3.0秒休止。休止中射撃/パルス不可、装填は進む。
- 各Waveパルス1回。総敵W+2、同時上限min(4,W+1)。
- Level案の保守的開始を優先：最初は1体、以後3.2秒以上間隔で1体ずつ補充。満枠の予約を一括放出しない。
- W1直進、W2以降は緩い旋回も組合せる。今回デコイ・新しい急加速/切返しギミックは追加しない（Plannerの簡素化案採用）。
- 外周340、コア判定34を基準。基本動径速度min(26,22+0.5*(W-1))、総移動速度32px/s上限。キャンペーン値は変更しない。
- 設定データを明瞭に集約。タイトル説明の耐久・リロード・休止は設定から生成する。
- 命中率＝実敵に命中した発射数/全発射数。複数撃破も分子1、0発は「—」。到達Wave＝開始した最大Wave。
- マウス/既存キー照準、左クリック/Space/Enter射撃、右クリック/Shift/Eパルス、M維持。再挑戦はW1からラン全体初期化。
- 状態遷移入力の貫通、リピート/長押し、ネイティブclickとの二重発火を防ぐ。
- 個体別履歴。予測は観測履歴のみ、照準に近い観測個体を対象にする。無限中の外れで全真位置を開示しない。

## 受け入れ基準・検証
1. 既存10Rキャンペーン、1発勝敗、スコア/デコイ/導線の回帰なし。
2. 無限開始→複数同時敵→直撃/爆風撃破→補充→全処理→休止→次Waveが継続。
3. 外れ消費・2秒装填、不成立射撃、飛翔中の他入力、命中発射の重複計上なし。
4. 突破ごと耐久減少・重複減算なし、0で結果固定。撃破/到達Wave/命中率表示、再挑戦/タイトル初期化。
5. タイトルから両モードへ入り既存canvas/UI入力を使用可能。数値説明と設定一致、休止中入力制限。
6. `node projects/vector-strike/tests/acceptance.test.js`を含む自動検証。実ブラウザ（既存Playwright等）で見た目・操作・結果・導線確認。

## プレイ領域サイズ方針（2026-11-05）
- ユーザー承認：レスポンシブ縮小でレーダーが小さくなるのを避け、固定プレイ領域を優先。画面が小さい場合は最低ウィンドウサイズを案内し、対象外とする。
- 現在の固定Canvasは960×720 CSS px。左右HUD・余白とヘッダーを含む最低表示領域は1504×784 px。
- 未満のウィンドウでは全画面警告を表示し、マウス入力を覆う。キーボードも開始・照準・発射などのゲーム入力を拒否する。表示領域を広げると警告が消える。
- CSS Grid/CSS aspect ratioは画面に合わせてCanvasを縮小しない。既存の論理キャンバス座標とポインター変換は維持する。
- 最低寸法での実ブラウザ確認と、最小未満で警告が出てCanvasサイズを維持することを受け入れテストする。
