## 0. デザインコンセプトと前提条件の整理

### デザインコンセプト
**「TACTICAL SONAR & RAILGUN — 暗闇の幾何学と閃光のカタルシス」**

通常時は深海・暗夜の戦術指揮室（CIC）を思わせるストイックな単色系（フォスファー・シアン／エメラルド）のレーダースコープに徹し、プレイヤーの視覚認知リソースを「点群の並び（距離・角度・時間差）から敵の未来位置を幾何学的に読むこと」へ100%集中させる。
そして1発の徹甲弾を放った瞬間、静寂を破る白熱のレールガン閃光と「アンベール（完全軌道開示）」によって画面全体のコントラストを一気に解放する。

### 条件の区分（確定条件・委任決定・前提制約）
- **確定条件（変更不可）**:
  - PCブラウザ1画面完結（HTML / CSS / JS、外部ビルド・外部画像・外部音声アセット不使用）。
  - 通常時は敵本体不可視。ソナー（回転スイープ／戦術パルス）通過時のみブリップと残像を表示。
  - 完全1発勝負（1ラウンドにつき弾1発。命中＝即撃破CLEAR、外れまたは自機被弾＝即敗北FAILED）。
  - 全5ラウンド構成、自機は画面中央 `(0, 0)` 固定タレット、360度照準。
- **委任された決定事項（本仕様書で確定）**:
  - 画面レイアウト寸法、カラーパレット、タイポグラフィ、Canvas 2D描画レイヤー階層。
  - ブリップ（$t_0, t_{-1}, t_{-2}$）の形状・サイズ・減衰率・ベクトル補助線・Round 5デコイの微差表現。
  - 照準レティクルのリード（着弾所要時間・距離）表示UI。
  - 発射〜決着時のアンベール（答え合わせ）演出・ニアミス距離可視化・撃破エフェクト。
  - Web Audio API プロシージャル音源（全8系統）の合成アルゴリズムと数式パラメータ。
- **素材・利用権限およびアクセシビリティの前提**:
  - **外部素材ゼロ制約**: すべてのグラフィックスはHTML5 Canvas 2D APIおよびCSSで描画し、すべての音声はWeb Audio APIのオシレーターとホワイトノイズバッファで生成する（著作権・利用権限リスクゼロ）。
  - **色覚多様性・可読性配慮**: 通常／警戒／デコイ／実弾軌跡の区別を「色相」だけに頼らず、**「形状（円／菱形／二重環）」「線種（実線／破線／点線）」「明度差」「ラベル文字列」**の多重エンコーディングで識別可能にする。

#### レイアウト寸法仕様
- **全体コンテナ**: 左右HUD各 `245px`、中央プレイ領域 `960px`、間隔・余白込みで最低幅 `1504px`。高さはヘッダー・プレイ領域・余白込みで最低 `784px`。
- **中央レーダー領域**:
  - 論理Canvas解像度・画面表示サイズ: **`960 × 720 px`**。CSSでのビューポート追従縮小は行わない。
  - **レーダー原点（自機タレット座標）**: Canvas中心 `(480, 360)`。
  - **有効レーダー外周半径 ($R_{max}$)**: **`340 px`**（外周余白に方位角ラベル `000°`〜`330°` と外枠ベゼルを描画）。
  - **距離換算スケール**: 画面上の `1 px = 1 m`（最大探知半径 `340 px = 340 m`）と定義することで、プレイヤーの目測・計算とHUD表示数値を1対1で完全一致させる。
- **左右HUDパネル（幅 `220px〜260px`）**:
  - **左パネル（戦術情報）**: 現在のラウンド番号・ターゲットコード名・軌道特性ヒント・最新検知時の距離／経過時間・現在の脅威度ステータス・累計スコア。
  - **右パネル（兵装・照準テレメトリ・操作案内）**:
    1. **主砲状態**: `RAILGUN: READY`（発射前）／ `DISCHARGED`（発射後）。残弾インジケータ（1発のみ）。
    2. **戦術パルス状態**: `TACTICAL PULSE: READY [R-CLICK / SHIFT]`（未使用時はシアン点灯、使用後は `DEPLETED` で暗転、温存時は `+NO-PULSE BONUS` 表示）。
    3. **リアルタイム照準テレメトリ**: 現在カーソルがある位置の「方位角（`AZM`）」「中心からの距離（`RNG`）」「その座標までの弾到達秒数（`TTI: Time To Impact`）」。
    4. **常時操作ガイド**: マウス／キーボード両対応の操作一覧。
- **オーバーレイ層（Canvas上に重なるモーダル／バナー）**:
  - **タイトル画面**: レーダースコープが背景で実際に回転する上に半透明戦術ブリーフィング枠を表示。`[START OPERATION (CLICK / SPACE)]` とラウンド選択ボタンを配置。
  - **決着・アンベールバナー（CLEAR / FAILED）**: 発射後のアンベール（軌道答え合わせ）を隠さないよう、**画面上部または下部のスリムバナー（高さ120px程度）**として表示し、中央のレーダー上の軌道・誤差表示が100%視認できるようにする。

## 2. レーダースコープの視覚表現（Canvas 2D）

レーダースコープは単なる背景ではなく、プレイヤーが「距離」と「角度」を測るための**精密な幾何学定規**として機能する。

### 2.1 距離リング（Range Rings）と危険域表示
中心 `(400, 400)` から以下の同心円を描画する。
1. **外周ベゼルリング（半径 `340px = 340m`）**:
   - 線幅 `2.5px`、色 `rgba(0, 240, 200, 0.55)`。外側4方向に短いブラケット装飾を付与。
2. **主距離リング（半径 `100px`, `200px`, `300px`）**:
   - 線幅 `1.2px`、実線。各リングの北側（`000°` 軸のすぐ右横）に `100m`, `200m`, `300m` の数値ラベルを `11px monospace`（色 `rgba(0, 240, 200, 0.55)`）で描画。
3. **副距離リング（半径 `50px`, `150px`, `250px`）**:
   - 線幅 `1.0px`、破線 `setLineDash([4, 6])`。
4. **内周危険域（DANGER ZONE：半径 `100px` 以内）**:
   - 半径 `100px` のリングを赤系破線 `rgba(255, 60, 80, 0.35)` で強調し、敵の推定位置（または最新検知点）が半径 `120px` 以内に侵入した瞬間から、内周 `100px` 円内を `rgba(255, 30, 60, 0.06)` で脈動（周期 `0.6s` のサイン波点滅）させる。
5. **自機防衛コア（中心半径 `12px`）**:
   - 中心 `(400, 400)` に八角形または二重円のタレットシンボルを描画し、現在のマウス照準方向へ長さ `22px` の砲身ベクトルインジケータを向ける。敵が中心半径 `14px`（接触判定閾値）に達すると自機被弾となる境界を視覚的に示す。

### 2.2 方位目盛り（Azimuth Grid）
- **十字主軸（`000°`, `090°`, `180°`, `270°`）**:
  - 中心から外周 `340px` まで線幅 `1.0px`、`rgba(0, 240, 200, 0.20)` の実線。
- **30度刻み放射線（`030°`, `060°`, `120°`, `150°`, `210°`, `240°`, `300°`, `330°`）**:
  - 半径 `50px` から `340px` まで線幅 `0.8px`、`rgba(0, 240, 200, 0.10)` の細い実線（中心付近が線でごちゃつくのを防ぐため半径 `50px` 内側は抜く）。
- **外周角度ティック（目盛り）**:
  - 外周 `340px` 上に **5度刻み** で長さ `5px` の短目盛り、**15度刻み** で長さ `9px` の中目盛り、**30度刻み** で長さ `13px` の長目盛り＋角度数値ラベル（`000°`, `030°` ... `330°`、北＝上を `000°` とする時計回り表記、または数学角併記）を描画する。

### 2.3 回転スイープバー（Sweep Bar）とグラデーション残光
- **スイープ回転方向・周期**:
  - 時計回り（Clockwise）。標準周期は1周約 `2.0〜2.4秒`（Planner定義の角速度パラメータに従う）。
- **描画構成**:
  1. **リーディングエッジ（先頭走査線）**:
     - 現在のスイープ角 $\theta_{sweep}$ に沿って中心 `(400, 400)` から半径 `340px` まで引く高輝度ライン（線幅 `2.0px`、色 `#00FFCC`、`shadowBlur: 8`、`shadowColor: '#00FFCC'`）。
  2. **扇形残光トレイル（Trailing Sector）**:
     - $\theta_{sweep}$ から逆回転方向に **角度幅 `55°`（約 `0.96 rad`）** の扇形を、18〜24分割の微小扇形（スライス）で描画する。
     - 各スライス $i$ の不透明度 $\alpha_i$ を指数減衰 $\alpha_i = 0.26 \times (1 - i / N)^2$ で滑らかにフェードアウトさせ、ブラウン管フォスファー（蛍光体）の残光感をCanvas 2D上で軽量かつ美しく再現する。

### 2.4 戦術パルス（Tactical Pulse：1ラウンド1回限定の補助ソナー）
プレイヤーが右クリック（または `Shift` キー）を押した瞬間に発動するアクティブソナー波。
- **波紋アニメーション**:
  - 中心 `(400, 400)` から外周 `340px` まで、**所要時間 `0.35秒`（拡大速度 約 `970 px/s`）** で急速に広がるシアンブルー（`#38BDF8`）の二重リング波紋を描画する。
  - 波紋リングの線幅は開始時 `4.0px` → 外周到達時 `1.5px`、内側に幅 `25px` のリング状グラデーション発光を伴う。
- **検知挙動**:
  - パルス波紋の半径 $R_{pulse}(t)$ が敵の現在距離 $r_{enemy}$ を通過した瞬間に、通常のスイープ検知と同様に最新ブリップ $t_0$ を更新・発光させ、`playSonarPing()` を鳴らす。
- **HUD連動**:
  - 発動と同時に右HUDの `TACTICAL PULSE` インジケータが `[ DEPLOYED ]`（グレーアウト）に切り替わり、スコープ外周に一瞬 `ACTIVE PING DEPLOYED` の戦術テキストがフラッシュする。

## 3. ブリップ（敵反応点）と残像履歴の視覚表現

敵本体は通常時一切描画せず、スイープ（または戦術パルス）が敵を通過した座標に生成される **最大3世代のブリップ履歴（$t_0, t_{-1}, t_{-2}$）** と **補助ベクトル表現** によって敵の運動状態を伝える。

### 3.1 世代別ブリップ（$t_0, t_{-1}, t_{-2}$）の視覚ヒエラルキー
新しい検知が発生するたびに、既存の $t_0 \to t_{-1}$、$t_{-1} \to t_{-2}$ へシフトし、$t_{-3}$ 以前は消去（ただし内部のアンベール用全履歴配列には保持）する。

| 世代 | 役割 | 形状・サイズ・アニメーション仕様 | 輝度・不透明度（時間減衰） | ラベル表示 |
| :--- | :--- | :--- | :--- | :--- |
| **$t_0$ (最新点)** | 直近の検知位置 | ・**中心コア**: 半径 `5.0px` の塗りつぶし円（`#FFFFFF`）<br>・**外周発光円**: 半径 `9.0px`（`#00FFAA`, `shadowBlur: 14`）<br>・**ソナー波紋リング**: 検知瞬間（経過 `0.0s`）から `0.8s` かけて半径 `6px` → `34px` へ広がりながら消える波紋（線幅 `1.5px`） | 検知直後 $\alpha = 1.0$<br>次のスイープまで経過時間 $\Delta t$ に応じ $\alpha = \max(0.65, 1.0 - 0.15 \Delta t)$ を維持（消えずに残る） | 右上に小さく<br>`NOW` または距離 `215m`<br>（`10px monospace`） |
| **$t_{-1}$ (1回前)** | 1周期前の位置 | ・**中空リング＋中心小点**: 半径 `5.5px` の中空円（線幅 `1.8px`）＋中心に半径 `2.0px` の点 | 固定不透明度 $\alpha = 0.55$<br>色 `rgba(0, 255, 170, 0.55)` | 右上に小さく<br>`-1`（`9px monospace`） |
| **$t_{-2}$ (2回前)** | 2周期前の位置 | ・**破線リング（または小十字）**: 半径 `4.0px` の細い中空円（線幅 `1.2px`） | 固定不透明度 $\alpha = 0.25$<br>色 `rgba(0, 255, 170, 0.25)` | 右上に小さく<br>`-2`（`9px monospace`） |

### 3.2 ベクトル補助線と未来予測ヒント表現
「点と点を頭の中で結ぶ」認知負荷を助け、直進・旋回・加減速を視覚パターンとして即座に読めるようにする。
1. **過去軌跡ベクトル線（History Vector Line）**:
   - 2点以上検知されている場合、$t_{-2} \to t_{-1}$ を細い点線（`setLineDash([2, 4])`, 線幅 `1.0px`, $\alpha = 0.22$）で結び、$t_{-1} \to t_0$ を破線（`setLineDash([5, 4])`, 線幅 `1.5px`, $\alpha = 0.42$）で結ぶ。
   - **視覚効果**:
     - $t_{-2} \to t_{-1}$ と $t_{-1} \to t_0$ の**角度差**を見れば「直進」か「右／左旋回（スパイラル・ジグザグ）」かが一目でわかる。
     - $t_{-2} \to t_{-1}$ と $t_{-1} \to t_0$ の**線分の長さの比**を見れば「等速」か「急加速（線分が伸びた）」かが一目でわかる。
2. **線形外挿ゴーストガイド（Velocity Extrapolation Hint）**:
   - $t_{-1}$ と $t_0$ の2点が揃っているとき、$t_{-1} \to t_0$ のベクトルをそのまま $t_0$ の先へ **0.5周期分だけ極薄の点線矢印（`setLineDash([2, 6])`, $\alpha = 0.18$）** として延長描画する。
   - これにより、Round 1（等速直線）ではこの延長線上がそのまま未来位置の目安となり、Round 2（旋回）や Round 4（折れ線）では「線形延長からどれだけ内側／逆側へ曲がるか」を考える基準線（モノサシ）として機能する。

### 3.3 Round 5（DUAL ECHO / デコイ伴走）における本物とデコイの微差設計
Round 5では本物のターゲットに加え、偽のソナー反応（デコイ）が発生する。「初見では惑わされるが、注意深く観察・聴取すれば必ず論理的に見破れる」フェアな手がかりを**視覚2種＋音響1種＋軌道1種**の計4レイヤーで実装する。

| 識別要素 | 本物ターゲット (Real Target) | デコイ (Decoy Echo) | 見破り方（プレイヤーの攻略体験） |
| :--- | :--- | :--- | :--- |
| **① コア形状** | **真円（Circle）** コア＋安定した1重波紋 | **ひし形（Diamond / 45°回転正方形）** コア＋微細にブレる二重波紋 | ブリップの中心を凝視すると、デコイは角張った菱形をしており、2〜3フレームごとに `±1.5px` のデジタルノイズ揺らぎ（グリッチ）が入る。 |

## 6. Web Audio API プロシージャル音響設計

`/old/work/games/projects/overdrive-rpg/src/audio.js` の `SoundEngine` アーキテクチャ（外部音声ファイルゼロ、遅延 `AudioContext` 初期化、`createNoiseBuffer()` によるホワイトノイズ生成、ヘッドレス環境でもエラーを起こさない `try/catch` ガード、`localStorage` 連動ミュート機能）を完全踏襲し、本作専用の8系統の戦術プロシージャル音源を定義する。

### 6.1 基盤クラス設計と安全ガード仕様
- **マスターゲイン**: `masterGain.gain.value = 0.35`（ミュート時は `0.0`）。
- **ホワイトノイズバッファ**: `sampleRate * 1.0` 秒のモノラル乱数バッファ（`data[i] = Math.random() * 2 - 1`）を初期化時に1回生成し、爆発音・レールガン放電音・デコイノイズに再利用する。
- **ヘッドレス・自動テスト安全保証**: `ensureContext()` 内で `window.AudioContext || window.webkitAudioContext` の存在確認と `ctx.resume().catch(() => {})` を徹底し、音声再生が失敗してもゲームロジックは1ミリも停止させない。

### 6.2 距離連動ソナーPing音のピッチ計算式
ソナー（回転スイープまたは戦術パルス）が敵を捉えた瞬間に鳴らす `playSonarPing(distanceRatio, isDecoy)` は、**敵が中心に近いほど周波数（ピッチ）が高くなり、倍音が鋭くなる**ことで、画面を見なくても耳だけで接近距離と緊迫感が直感できるように設計する。

- **正規化距離比率 $d_{norm}$ の定義**:
  $$d_{norm} = \text{clamp}\left(\frac{r_{enemy}}{R_{max}}, 0.0, 1.0\right) \quad (R_{max} = 340\text{px})$$
  （※外周 $r = 340\text{px}$ のとき $d_{norm} = 1.0$、中心 $r = 0\text{px}$ のとき $d_{norm} = 0.0$）
- **接近度パラメータ $p$（Proximity）**:
  $$p = 1.0 - d_{norm} \quad (0.0 \le p \le 1.0)$$
- **基本周波数 $f_{ping}$ の指数マッピング式**:
  $$f_{ping}(d_{norm}) = 520 \times 2.6^{(1.0 - d_{norm})^{1.25}} \text{ [Hz]}$$
  - 外周付近（$d_{norm} = 0.9, p = 0.1$）のとき：約 **$560\text{ Hz}$**（低く落ち着いた深海ソナー音）
  - 中距離（$d_{norm} = 0.5, p = 0.5$）のとき：約 **$775\text{ Hz}$**（明瞭な中音Ping）
  - 危険域境界（$d_{norm} = 0.3, p = 0.7$）のとき：約 **$958\text{ Hz}$**（緊迫感のある高音Ping）
  - 至近距離（$d_{norm} = 0.1, p = 0.9$）のとき：約 **$1,200\text{ Hz}$**（鋭い警報域Ping＋第2倍音強調）

### 6.3 全8系統のプロシージャル音響合成パラメータ一覧

#### ① `playSweepPass()` — スイープ基準角（北 `000°`）通過時の微かな環境パルス音
スイープが1周して `000°` を通過するたびに微かに鳴る、潜水艦CICのような低周波パルス。
- **Oscillator**: `sine` 波
- **Frequency**: `95 Hz` → `55 Hz`（`0.12s` の `exponentialRampToValueAtTime`）
- **Gain Envelope**: `0.001` → `0.08`（アタック `0.015s`）→ `0.001`（リリース `t + 0.14s`）

#### ② `playSonarPing(distanceRatio, isDecoy = false)` — 敵検知ソナーPing音
最重要サウンド。距離に応じたピッチ変化と、Round 5デコイの微細な音色差を持つ。
- **本物ターゲット（`isDecoy === false`）**:
  - **主音（Osc 1）**: `sine` 波、周波数 $f_{ping}$（瞬間アタックで $1.02 \times f_{ping} \to f_{ping}$ へ `0.02s` で落ち着く水滴的エンベロープ）。
    - Gain: `0.30`（`t`）→ `0.001`（`t + 0.28s`、指数減衰）。
  - **倍音エコー（Osc 2）**: `triangle` 波、周波数 $2.0 \times f_{ping}$。
    - Gain: 接近度 $p$ に比例して $0.04 + 0.12 \times p$（遠い時は丸い音、近い時は倍音が強く鋭い金属音になる）→ `0.001`（`t + 0.16s`）。
- **Round 5 デコイ（`isDecoy === true`）の微差合成**:
  - **主音（Osc 1）**: `sine` 波、周波数 $f_{ping} \times 0.97$。
  - **デチューン干渉音（Osc 2）**: `triangle` 波、周波数 $f_{ping} \times 1.414$（増四度／トライトーン系の不協和倍音）を Gain `0.10` で混入し、わずかに濁った金属うなりを生じさせる。
  - **微弱ノイズ層**: ホワイトノイズを `bandpass` フィルタ（中心周波数 `2200 Hz`, `Q = 8.0`）に通し、Gain `0.06`、持続 `0.09s` で重ねる。

#### ③ `playDangerHeartbeat(distanceRatio)` — 危険域（半径120m以内）侵入時の接近警報パルス
敵が危険域に入った際、スイープ検知時または一定周期で鳴る緊迫した2連パルス音。
- **Oscillator**: `sawtooth` 波 ＋ `lowpass` フィルタ（カットオフ `900 Hz`）
- **Frequency**: 1打目 `440 Hz`（`t` 〜 `t + 0.06s`）、2打目 `587.33 Hz`（`t + 0.08s` 〜 `t + 0.15s`）
- **Gain**: `0.16` → `0.001`

#### ④ `playTacticalPulse()` — 戦術パルス（右クリック補助ソナー）発動音
全方位へ高出力のアクティブソナー波を放つ、澄んだ上昇チャープ＋残響音。
- **Osc 1（スイープチャープ）**: `sine` 波、`320 Hz`（`t`）→ `1,480 Hz`（`t + 0.18s`、指数ランプ）→ `960 Hz`（`t + 0.35s`）。
  - Gain: `0.26` → `0.001`（`t + 0.36s`）。
- **Osc 2（サブベース波紋）**: `triangle` 波、`140 Hz` → `60 Hz`（`t + 0.25s`）。

#### ⑤ `playRailgunShot()` — 1発限りの高速徹甲弾（レールガン）発射音
1ラウンドに1回しか鳴らないため、最高の重量感と切れ味を持たせる3レイヤー合成音。
1. **レイヤー1（重低音電磁キック）**:
   - `square` 波、`180 Hz`（`t`）→ `32 Hz`（`t + 0.22s`、指数ランプ）。
   - Gain: `0.40` → `0.001`（`t + 0.24s`）。
2. **レイヤー2（高周波プラズマ放電チャープ）**:
   - `sawtooth` 波、`2,400 Hz`（`t`）→ `280 Hz`（`t + 0.12s`、指数ランプ）。
   - Gain: `0.28` → `0.001`（`t + 0.13s`）。

   - ホワイトノイズバッファ ＋ `bandpass` フィルタ（周波数 `1,600 Hz` → `400 Hz`, `Q = 1.8`）。
   - Gain: `0.35` → `0.001`（`t + 0.18s`）。

#### ⑥ `playTargetHit(isBullseye = false)` — ターゲット命中・撃破音（カタルシス爆発＋勝利チャイム）
`overdrive-rpg/src/audio.js` の `playArmorBreak()` と `playExtraTurnReady()` の快感設計を融合した撃破サウンド。

#### ⑦ `playTargetMiss()` — 弾外れ・作戦失敗時の減衰トーン
外れた瞬間の「静まり返る虚脱感」と「即リトライへの切り替え」を邪魔しない短い下降2音。
- **Oscillator**: `sawtooth` 波 ＋ `lowpass` フィルタ（`650 Hz`）

#### ⑧ `playPlayerHit()` — 自機被弾時の重低音クラッシュ＆トライトーン警報

## 7. 状態変化と操作フィードバックの対応マトリクス（実装チェックリスト）

Programmerが実装時に迷わないよう、プレイヤーの入力・状態遷移に対する視覚・音響フィードバックの1対1対応を以下にまとめる。

| トリガー／状態変化 | 視覚フィードバック（Canvas / HUD） | 音響フィードバック（SoundEngine） |
| :--- | :--- | :--- |
| **ラウンド開始 / リトライ直後** | レーダー盤面クリア、スイープが `000°` から回転開始、HUDの弾薬 `1/1`・パルス `READY` に復帰 | 短い起動確認ビープ（`880Hz` → `1320Hz`, `0.06s`） |
| **スイープが北（`000°`）を通過** | `000°` 目盛りが一瞬ハイライト | `playSweepPass()` |
| **スイープが敵を通過（通常距離）** | 通過座標に $t_0$ ブリップ生成＋波紋拡大、過去点を $t_{-1}, t_{-2}$ へシフトし破線ベクトル更新 | `playSonarPing(distanceRatio, isDecoy)` |
| **スイープが敵を通過（半径120m以内）** | 内周リングが赤〜アンバーで脈動、ブリップ外光が `#FF3355` に変化、HUD Threatが `CRITICAL` | `playSonarPing(...)` ＋ `playDangerHeartbeat()` |
| **右クリック / Shift（戦術パルス）** | 中心から半径 `340px` へ `#38BDF8` の二重波紋が `0.35s` で拡大、敵通過時にブリップ更新、HUD `DEPLETED` | `playTacticalPulse()` （＋敵通過時に `playSonarPing()`） |
| **左クリック / Space（徹甲弾発射）** | 中心マズルフラッシュ、弾頭とシアン光跡が照準方向へ高速飛翔、HUD `RAILGUN: DISCHARGED` | `playRailgunShot()` |
| **弾が本物の敵に命中（CLEAR）** | ヒットストップ `0.06s` → 白フラッシュ＆シェイク → 破片パーティクル飛散 → **完全アンベール（赤実線の真軌道＋検知点一致）** → 精度・ブラインド評価表示 | `playTargetHit(isBullseye)` |
| **弾が外れて通過・画面外（FAILED）** | **完全アンベール（赤実線の真軌道＋敵実体＋水色の自機弾軌跡）** → 最接近点（CPA）を黄色点線で結び **`MISS BY XXm`** と外れ要因診断を表示 | `playTargetMiss()` |
| **敵が自機中心に接触（FAILED）** | 中心に赤色爆発リング＆シェイク → **完全アンベール** → `BASE BREACHED` バナー表示 | `playPlayerHit()` |
| **決着中に R / Space / Click 入力** | 演出待機なしで `0.1s` 以内に同ラウンド再開始（または次ラウンドへ進行） | 起動確認ビープ |
